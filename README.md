# safestore-beta-releases

**Beta** installers and auto-update feeds only. No app source.

Builds here are pre-releases for testers who have unlocked the beta channel in SafeStore
(Settings → Unlock codes). Shooters on the normal release don't see them. The stable releases
live in [SafeStore-releases](https://github.com/CazzaCoder/SafeStore-releases).

- Mac feed: `appcast.json` · Windows feed: `appcast-win.json` (written by the publish scripts)
- Build numbers are shared with stable: a beta build N is the same bytes if it is later promoted.
